# Car Showroom

Веб-застосунок віртуального автосалону на базі REST API [DummyJSON](https://dummyjson.com/) (категорія `vehicle`).


**Посилання на розгорнутий застосунок:** 

## Інструкція

1. Встановіть залежності:
   ```bash
   npm install
   ```
2. Запустіть проєкт у dev-режимі:
   ```bash
   npm run dev
   ```
3. Для production-збірки:
   ```bash
   npm run build
   ```

## Опис функціоналу
- **Головна сторінка:** каталог автомобілів з адаптивною сіткою, пошуком та фільтрацією (пошуковий запит за текстом, вибір марки зі списку та повзунок обмеження максимальної ціни).
- **Сторінка автомобіля:** розширена інформація про авто, технічні характеристики та фотогалерея.
- **Коментарі:** відображення відгуків з API та форма додавання власного коментаря з валідацією полів. Додані коментарі автоматично зберігаються в LocalStorage і не зникають після перезавантаження. 

## Технології 
- **Vite** — збірка.
- **React & TypeScript** — компонентна архітектура та типізація
- **Redux Toolkit & RTK Query** — автоматичне кешування запитів до API та централізований стан відгуків.
- **React Router** — навігація.
- **React Hook Form + Zod** — обробка форм та валідація.
- **LocalStorage** — збереження доданих коментарів 
- **CSS (Flexbox / Grid)** — адаптивна верстка.
